BMKG
Gratis · 1 Endpoint

Prakiraan cuaca per lokasi dari BMKG. Data berisi curah hujan (tp), suhu, kelembaban per interval 3 jam untuk setiap kode wilayah ADM4.

Kode ADM4 diatur di wqsa.env → BMKG_ADM4_CODES. Format: 32.04.15.2001
Endpoint: api.bmkg.go.id/publik/prakiraan-cuaca?adm4=...
Parameter: adm4 (kode wilayah BPS level desa/kelurahan) · Tidak perlu API key

SITALA KLHK
1 Endpoint

Sistem Informasi Indeks Kualitas Lingkungan Hidup. Berisi data IKA, IKU, IKL, IKLH per kabupaten/kota per tahun beserta target RPJMN.

Tahun diatur di URL SITALA pada wqsa.env → SITALA_URL.
Endpoint: sitala.kemenlh.go.id/iklh/apiIbex/indeksIklh/tahun/{tahun}
Parameter: tahun · API Key dari wqsa.env → SITALA_API_KEY
Catatan: SITALA mengembalikan semua kabkota dalam 1 request (tidak paginated)
